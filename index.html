FAQ

Before you buy

Is this safe to run on a real session?

Every sweep re-verifies itself afterward and reports exactly what changed. Still — always keep a backup before any batch or multi-file operation, same as you would for any tool that edits session data.

Does SessionTide need an internet connection?

No. It runs entirely locally and talks only to Pro Tools on the same Mac. The only network call is a one-time license check when you activate.

Is this affiliated with Avid or Pro Tools?

No. SessionTide is an independent tool built on Avid's public Pro Tools Scripting SDK (PTSL). It is not affiliated with, endorsed by, or sponsored by Avid Technology, Inc.
